# 错题账本

一个纯本地、纯标准库的小工具：**把「这道题我卡在哪」记下来 → 在浏览器里遮住答案重做一遍 → 点两个按钮处理掉 → 每周日出一张能打印的卷子**。

数据全部是纯文本 JSON：可以手改、可以备份、不联网、不依赖任何服务。

---

## 一、它跟普通的错题本不一样

英语那边，错一道题就是几个词不会，词本身就是可复用的单位——背会这个词，下次就能用。

数学不是。**同一道题不会再出现第二次**，所以「把题抄下来、下次再做一遍」的收益很有限：你记住的是这一题的答案，不是这一类题的解法。真正会重复犯的错长这样：

```
11-18  等价无穷小用在加减法里，把三阶项丢了
11-19  还是这个坑：1 − cos x 没先想 x²/2
11-21  根式差没看出是一次项，硬代值得了个 0/0
```

三道不同的题，**同一个断点**。

所以这个账本：

- 记的是**题**（题干、当时的错解、断在哪一步、答案、该怎么想）；
- 算账和复习的单位是**知识点**——`points` 字段，一道题挂 1–3 个；
- 周报里有一个「薄弱知识点」视图：同一个断点的题聚在一起，**错了三次的知识点自己会浮到最上面**。

「哪个知识点我错了三次」才是把错题记下来唯一真正的产出。其余都是副产品。

## 三、怎么用（三个场景）

| 场景 | 怎么做 |
|---|---|
| **记** | 做完题对答案，把错的那道丢给 AI：「这题我算成 X，帮我记一下」；也可以自己 `cuoti.py add` |
| **过一遍** | 开始菜单搜「错题本」（或双击 `错题本.cmd`）→ 浏览器打开卡片页，先自己重做，再点开对答案 |
| **打印** | 周日自动生成；也可以 `cuoti.py report --open` 手动出 |

过一遍的页面上每张卡片两个按钮：

- **☆ 收藏** → 变「★ 已收藏」，进收藏夹；搞懂了也还在
- **搞懂了** → 从「还没搞懂」移走；再点一次放回

点卡片本身是**揭晓**——`我的错解 / 断在哪 / 答案 / 该怎么想` 默认全遮住，只剩题干。

## 四、两件事要分清

| 你要做的 | 需要服务吗 |
|---|---|
| **让 AI 记录错题**（批改后 `add`） | ❌ 不需要。那是独立的一次命令行调用 |
| **周日自动出报告** | ❌ 不需要。计划任务自己跑 |
| **点按钮标记搞懂了 / 收藏** | ✅ 需要。按钮要写文件，所以得有个本地服务在跑 |

服务只在点按钮时有用；**关掉它不影响记录，也不影响周报**。
页面关掉 30 分钟后服务自动退出，不会再留进程。

## 五、一个 HTML，六个视图

页面标题是「**第 N 周**」——从你记下第一道题的那周算第 1 周，不是日历的周数。

| 视图 | 内容 |
|---|---|
| **过一遍** | 还没搞懂的题，遮挡模式，按「知识点错得最多」排序 |
| **薄弱知识点** | 反复错的摊开成一节，只错一次的排成标签（点标签跳到「还没搞懂」并过滤） |
| **表一 · 本周新增** | 这周记的题，顶部有错因分布 |
| **还没搞懂** | 全部未搞懂，按模块分组 |
| **收藏夹** | ★ 过的题 |
| **搞懂了** | 已搞懂的题，按搞懂日期倒序 |

顶部标签带计数，右侧搜索框只过滤当前视图（搜题干、知识点、卡点、答案）；**打印时只打印当前视图**。
本周没有数据时不会生成空表，会自动退回到最近有数据的一周。

### 打出来是卷子，不是清单

「过一遍」和「还没搞懂」两个视图**打印时会自动拆成两份**：

- 正面：只有题干 + 模块/知识点/错因 + 一行「答：」——你拿笔重做；
- 背面：另起一页的「答案」页，按 id 列出答案、断点、该怎么想——对答案用。

## 六、两种状态

```
   add              star
  ∅ ───► 还没搞懂 ◄──────────► ★ 收藏
          │  ▲                 │
   solve  │  │ unsolve         │  （两个标记互不影响）
          ▼  │                 │
        搞懂了 ────────────────┘
```

- `solve`（别名 `learn`）：搞懂了，从待做清单移走
- `unsolve`（别名 `unlearn`）：又不会了，放回来（`stuck` 不会被清掉）
- `star` / `unstar`：收藏 / 取消收藏

**「搞懂了」只有一个判据：不看答案能独立做出来。** 看懂解答不算。
**没有分数，也没有「错了几次」的计数。** 判断权归你，脚本只负责记录和呈现。

## 七、命令速查

```bat
set PY=D:\Python\python.exe
cd /d D:\小鲸鱼\数学错题

:: 录入一道
%PY% cuoti.py add "求 lim(x→0) (tan x - sin x)/x³" --topic 极限 ^
    --point 等价无穷小 --point 泰勒展开 --kind 方法 ^
    --answer "1/2" --my-work "tan x ≈ x, sin x ≈ x, 分子 = 0, 答 0" ^
    --stuck "加减法里直接做等价替换，把三阶项丢了" ^
    --fix "先通分成 tan x(1-cos x)，或泰勒展开到 x³" ^
    --source "2026-W47 660题 P42 T7"

:: 录入一批（推荐，省 token）
%PY% cuoti.py add --file seed\2026-W48.json
%PY% cuoti.py add --file examples\sample.json --date 2026-11-20

:: 处理
%PY% cuoti.py solve 20261123-001        :: 搞懂了（一次多个也行）
%PY% cuoti.py unsolve 20261123-001      :: 又不会了
%PY% cuoti.py solve "tan x - sin x"     :: 题干片段也行，命中多道会要求用 id
%PY% cuoti.py star 20261123-001
%PY% cuoti.py unstar 20261123-001

:: 查看
%PY% cuoti.py list                      :: 还没搞懂的
%PY% cuoti.py list --solved --all       :: 搞懂的 / 全部
%PY% cuoti.py points                    :: 哪个知识点错了三次  ← 最有用
%PY% cuoti.py stats                     :: 概览
%PY% cuoti.py weeks                     :: 按周统计

:: 界面与报告
%PY% cuoti.py app --open                :: 过一遍（review 是别名）
%PY% cuoti.py report --open             :: 出周报
%PY% cuoti.py report --week 2026-W47 --open
%PY% cuoti.py weekly                    :: 补漏 + 出当周（幂等，调度用）
%PY% cuoti.py doctor --task MathMistakeWeekly   :: 自检
```

`points` 的输出长这样，「← 反复错」就是你要补的地方：

```
知识点                  没搞懂   总数  最近        题号
等价无穷小              3        3     2026-11-21  20261118-001、… ← 反复错
二重积分                1        1     2026-11-23  20261123-001
```

批量导入 JSON 格式（`seed\*.json`，字段定义见 `SPEC.md` §5）：

```json
{"problems": [
  {
    "problem": "求 ∫₀¹ x·√(1−x²) dx",
    "topic": "一元积分",
    "points": ["定积分换元", "换元换限"],
    "kind": "计算",
    "my_work": "令 u = 1−x²，上下限还写 0 到 1，结果 2/3",
    "stuck": "换元之后没换上下限：x=0 时 u=1，x=1 时 u=0，符号还会翻一次",
    "answer": "1/3",
    "fix": "换元三件套一起换：被积式、dx、上下限",
    "source": "2026-W47 660题 P71 T11",
    "first_seen": "2026-11-20"
  }
]}
```

重复导入同一份文件是安全的：题干相同的题不会重复记，也不会覆盖已有的 `stuck`。

## 八、每周日自动生成

| 计划任务 | 触发 | 作用 |
|---|---|---|
| **MathMistakeWeekly** | 每周日 20:10 | 生成当周报告并打开 |
| **MathMistakeCatchup** | 每天 12:05 | 检查有没有漏的周，漏几周补几周（周日那天关机也不会丢） |

两者跑的是同一条幂等命令 `cuoti.py weekly`（只生成「已过周日 20:00、但还没生成」的周），所以重叠也无害。

```bat
schtasks /Query /TN MathMistakeWeekly        :: 查看状态
schtasks /Run   /TN MathMistakeWeekly        :: 立刻跑一次
schtasks /Run   /TN MathMistakeCatchup       :: 只看有没有漏的周
schtasks /Change /TN MathMistakeWeekly /ST 21:00   :: 改时间
schtasks /Delete /TN MathMistakeWeekly /F    :: 取消自动生成
```

不确定它跑没跑：

```bat
D:\Python\python.exe cuoti.py doctor --task MathMistakeWeekly
```

会告诉你：账本能不能读、多少道题、有几道缺知识点、上次出报告是几天前、任务下次运行时间与上次退出码。

## 九、手动改数据

`data\mistakes.json` 就是全部数据，直接改也行，改完跑 `cuoti.py report` 就能看到结果。
每次写入前的旧版本存在 `data\backup\`，改坏了可回滚。

## 十、题干怎么写

报告不联网、不带任何外部资源，**不能渲染 LaTeX**。题干用纯文本 + Unicode：

| 不要写 | 写成 |
|---|---|
| `\frac{1}{2}` | `1/2` |
| `x^2` | `x²` |
| `\sqrt{2}` | `√2` |
| `\le` | `≤` |
| `\int_0^1` | `∫₀¹` 或 `∫[0,1]` |
| `\alpha` | `α` |

`add` 发现题干里有 `\frac`、`$` 这类痕迹会给提醒，`doctor` 会统计还剩多少条。

## 十一、和 AI 的配合约定

见 `AGENTS.md`：任何数学作业、模拟卷、真题的批改，都会把**错的那道题和断点**当场 `add` 进这个库。

背完告诉 AI 一句「这题会了」，它会 `solve` 掉；说「收藏这题」，它会 `star`。
说「最近哪块最差」，它会跑 `points` 给你看反复错的那个知识点。
